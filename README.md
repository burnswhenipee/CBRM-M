CBRMix&Match
===============

CBRMix&Match is a program to convert CBR/CBZ comic files to PDF, PDF to comic formats, or to export images from PDF and comic files for inspection or editing.

It's based on https://code.google.com/p/cbr-converter/

What's new in this fork :

  - Window is now resizable so you can read the damn log. This is the main reason I undertook this project.
  - Fixed innumerable PDF issues.
  - Can now directly convert between CBR/Z - PDF - and image folders
